# PCL Download Restore

恢复 PCL 的游戏下载、本地整合包导入和在线整合包安装入口。基于 .NET 方法结构识别，完全离线运行，不需要 Python。

## 功能

- 恢复 Minecraft 原版下载列表入口。
- 恢复手动选择、拖入整合包及各格式安装分发。
- 恢复在线整合包版本的直接下载安装，保留独立的“另存为”按钮。
- 自动备份、检查、重复应用识别和恢复原版。
- 识别类型、方法、字段和调用关系，不使用固定偏移定位新版本。

## 使用

1. [下载源码 ZIP](https://github.com/yuyu107/PCL-Download-Restore/archive/refs/heads/main.zip) 并完整解压，保留 `lib` 文件夹。
2. 完全退出 PCL。
3. 将实际使用的 PCL EXE 拖到 **仅检查.cmd** 上。
4. 检查通过后，将同一个 EXE 拖到 **应用补丁.cmd** 上。
5. 重新打开 PCL，测试下载或整合包安装。

不必把 PCL 搬到脚本文件夹。包内不包含 PCL 启动器，也不提供游戏文件。

恢复时，退出 PCL，将 EXE 拖到 **恢复原版.cmd** 上。

## 环境与适配范围

- 使用系统自带 Windows PowerShell 和 .NET Framework 编译组件。
- 当前 r10 已由用户反馈在 Windows 7 和 Windows 11 可用。
- 目标是仍保留对应 VB/.NET Framework 代码结构的 PCL 构建。
- 已验证的真实样本是快照版 **2.99.0.0（414）**；文件资源中出现的 2.13.1 并非本次快照的实际程序集版本。
- 不承诺所有历史版、未来版或第三方修改版兼容；结构不匹配时停止，不写入目标 EXE。
- PCL CE、重构版、混淆版及强名称签名构建不在当前适配范围。
- 修复入口不会解决启动器自身的系统兼容、网络、资源失效或整合包内容问题。

## 备份

脚本在目标 EXE 旁创建：

- `<EXE>.pcl-offline-original.bak`：原版文件。
- `<EXE>.pcl-offline.txt`：原版及补丁后的散列记录。

请保留两者。PCL 更新或被其他工具修改后，记录不匹配时脚本会停止；可把新原版放到新文件夹中重新操作，避免混用旧备份。

支持迁移此前本项目测试阶段的固定版 v1–v6 和 Python 通用版，需保留它们对应的原版备份。恢复操作会同时撤销本工具的全部修复。

## 实现

`Run-Patch.ps1` 内嵌实际使用的 C# 核心，避免外部源码版本混用；`PclPatchCore.cs` 是对应源码，供阅读和维护。

脚本显式选择 C# v3.5/v4.0 编译器，并分别处理 CLR 2 与 CLR 4 的引用要求。使用 dnlib 读取、修改和重写托管方法；写入前后检查方法求值栈，输出成功后才备份并替换目标文件。

修改目标 EXE 前不运行它。所有解析依赖均随包附带，不会首次联网下载运行环境。

## 验证

- 核心源码实际编译并对真实快照执行过程序集重写。
- 修改方法写入前后的求值栈检查通过。
- 测试样本的托管资源、原生图标和版本资源逐字节保持一致。

- Windows 7、Windows 11 的可用性来自用户实机反馈；尚未建立所有 PCL 版本和整合包格式的完整测试矩阵。
